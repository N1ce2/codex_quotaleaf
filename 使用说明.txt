GPT 额度卡片 · Windows

EXE 分享版：解压完整 ZIP 后双击 codex_quotaleaf.exe，无需 Python / PyQt5。
源码版：双击“启动额度卡片.vbs”，需要 Python / PyQt5。
两种方式都需要本机已安装并登录的 Codex，不会携带作者的账号。
启动器优先使用项目内 .venv，其次使用 PATH 中的 pythonw.exe。安装方法见 README.md。

操作
· 拖动卡片空白区域移动位置，靠近屏幕边缘自动吸附。
· 图钉：切换始终置顶。
· 刷新图标：立即查询。
· 齿轮或双击卡片空白处：打开个性化设置。
· 右键卡片：锁定位置、紧凑模式、背景图、隐藏到托盘或退出。
· 系统托盘图标：点击恢复；右键可退出。
· 任务状态字体：正在运行白色，等待确认橙色，已完成绿色。
· 点击运行任务仅跳转并保留显示；等待确认 / 已完成跳转后清除对应提醒。
· EXE 设置保存在 %LOCALAPPDATA%\codex_quotaleaf\state，源码设置保存在项目 state 文件夹。
· 设置中可以调整配色、强调色、圆角、背景不透明度、背景图遮罩和等比例缩放。
· 缩放支持 50%—250%，文字、图标、图片、间距与圆角统一缩放，不支持拉伸。
· 背景不透明度只影响背景，文字保持清晰。
· 默认圆角 24 逻辑像素，按参考图片近似；可在设置中微调。
· 登录 Windows 时自动启动默认关闭，需要时在设置中开启。

额度来源
通过官方 Codex App Server 的 account/rateLimits/read 只读接口，复用本机 Codex 的登录状态。
不读取或复制你的账号密码/令牌，不提交模型请求或充值。
左下角可查看剩余重置卡，选择卡片并确认后才使用；成功后自动同步额度和剩余卡数。
离线或卡片数据未同步时无法使用，请先刷新。使用会消耗所选卡片，不能撤回。
显示的是 Codex 的 5 小时/每周等额度，不代表 ChatGPT 所有模型的剩余消息数。
默认每 3 秒刷新，可在设置中调整为 3—3600 秒，支持服务更新通知；倒计时每秒更新。
请求尚未完成时不会重叠发送新的查询；断网后自动重连。
未知额度显示“—”，不会将未知当成 100% 或 0%。
网络失败时会保留上次数据并明确标记，自动重连。
如果未登录，请先在 Codex 中登录 ChatGPT 账号，再点击刷新。

文件
state/settings.json：个性化设置及窗口位置。
state/usage-cache.json：最近一次额度与时间，不含账号令牌。
state/error.log：仅发生程序异常时生成。

官方接口说明：https://learn.chatgpt.com/docs/app-server
